## Brand & Style

This design system embodies high-velocity software creation, catering directly to builders, technical founders, and product orchestrators operating in the AI and vibe-coding era (Cursor, Claude Code, Antigravity). The aesthetic is grounded in a deep, atmospheric dark slate environment punctuated by electric, hyper-precise spectral accents. It projects clarity, velocity, and architectural discipline.

The visual style merges **Modern Technical Minimalist** precision with **Refined Glass & Tonal Layering**. Surface layers leverage subtle hairline borders, deep translucent dark slate backdrops, and intentional glow states to create a command-center tactile feel. The interface feels lightweight yet resilient—built for dense technical canvases, markdown export views, structured node trees, and interactive roadmaps.

## Colors

The palette is engineered around an immersive low-luminance canvas, optimizing contrast for long architecture and planning sessions while preserving optical hierarchy.

- **Primary (`#6366F1`) & Secondary (`#3B82F6`)**: Work synergistically across interactive triggers, execution paths, and dynamic brand states. Primary drives structural actions, pipeline triggers, and high-priority selections. Secondary handles navigational accents, links, and informational tags.
- **Tertiary / Status Emerald (`#10B981`)**: Signals production readiness, valid configurations, code generation readiness, and synced deployment states.
- **Named Accents**: `accent-violet` (`#7209B7`) provides creative depth for ideation phases and AI prompt generation nodes, while `status-amber` (`#F59E0B`) marks dependency bottlenecks and active generation states.
- **Neutrals**: Rooted in deep slate `#0B0F17` (base viewport), layering up through `#0F172A` (panels/sidebars) to `#1E293B` (elevated cards, inspect sheets), delineated strictly by hairline borders (`rgba(148, 163, 184, 0.12)`) rather than heavy dropshadows.

## Typography

The type scale marries the geometric, tech-forward impact of **Outfit** for structural headings with the utilitarian legibility of **Inter** for dense interface panels, specifications, and code prompts.

- **Headlines (Outfit)**: Utilize negative tracking (`-0.01em` to `-0.025em`) to retain tight structural composure across large display contexts.
- **Interface & Body (Inter)**: Maintains open vertical rhythm for scanability across dense lists, step trees, and technical summaries.
- **Labels & Micro-data**: Always use `Inter` medium or semi-bold with slightly expanded letter-spacing (`0.01em` to `0.04em`) when rendered in uppercase for statuses, keyboard shortcuts, or metadata nodes.

## Layout & Spacing

The layout is built on a 12-column responsive fluid grid designed to support dense, interactive productivity tooling. 

- **Desktop (>= 1280px)**: 12 columns with `gutter-lg` (`2rem`) and `margin-desktop` (`2.5rem`). Utilizes fixed persistent navigation alongside fluid interactive workspaces (canvas and split inspect views).
- **Tablet (768px - 1279px)**: 8 columns with standard `gutter` (`1.25rem`), shifting auxiliary parameter sidebars into collapsible slide-overs.
- **Mobile (< 768px)**: 4 columns with `gutter-sm` (`0.75rem`) and `margin-mobile` (`1rem`). Split views convert into stepped card tabs.

Component padding adheres to a strict 4px/8px modular rhythm: micro gaps (`space-xs`, `space-sm`) structure metadata and icon-label locks, while `space-md` through `space-xl` handle container interiors and card module separation.

## Elevation & Depth

Visual hierarchy uses tonal surface layering combined with sharp 1px glassmorphic borders rather than opaque, heavy drop shadows.

- **Level 0 (Canvas Base)**: `#0B0F17` — Infinite canvas or foundation shell, no borders, ambient noise or fine grid mesh overlay.
- **Level 1 (Panels & Sidebar)**: `#0F172A` with a right/top 1px border of `border-subtle` (`rgba(148, 163, 184, 0.12)`).
- **Level 2 (Cards & Spec Modules)**: `#1E293B` with full 1px border (`border-subtle`). On hover or focus, the border transitions to `border-active` (`rgba(99, 102, 241, 0.4)`) accompanied by a subtle tinted back-glow: `0 8px 24px -4px rgba(99, 102, 241, 0.15)`.
- **Level 3 (Modals, Command Palettes & Floating Inspectors)**: Semi-translucent `#1E293B` (at 90% alpha with `backdrop-filter: blur(16px)`), framed with a high-contrast border of `rgba(255, 255, 255, 0.12)` and elevated via dual soft shadows: `0 20px 40px -15px rgba(0, 0, 0, 0.6), 0 0 0 1px rgba(255, 255, 255, 0.08)`.

## Shapes

The shape grammar is set to `2` (Rounded), providing modern ergonomics while retaining an intentional, engineered feel.

- **Standard Elements (Buttons, Inputs, Badges, Tokens)**: `0.5rem` (8px). This creates crisp alignment in dense UI clusters.
- **Structural Containers (Cards, Dialogs, Inspector Panels)**: `rounded-lg` (`1rem` / 16px).
- **Floating Overlays & Pill Badges**: Contextual `rounded-full` is reserved exclusively for system status indicators, pill filters, and prompt command hints.

## Components

### Buttons
- **Primary**: Solid gradient or rich fill (`#6366F1` transitioning subtly to `#4F46E5`), crisp white text, 8px corner radius. Includes a subtle inset top highlight: `inset 0 1px 0 rgba(255, 255, 255, 0.2)`. On hover: brightness increases by 8% with an indigo ambient glow.
- **Secondary / Ghost**: Background `rgba(30, 41, 59, 0.7)` with `1px` border of `border-subtle`. Text is `#F8FAFC`. On hover: background shifts to `#334155` with crisp border brightening.
- **Prompt Action / Build Button**: Special variant utilizing vibrant indigo with an animated emerald pulse badge (`#10B981`) denoting Cursor/Claude synchronization.

### Cards & Spec Panels
- Base `#1E293B` background, border `1px solid rgba(148, 163, 184, 0.12)`.
- Padding: `space-lg` (`1.25rem`). Card headers feature metadata tags aligned right, primary title left in `Outfit` 16px semi-bold.

### Chips & Status Badges
- **Status Badges**: Pill-shaped or 6px rounded enclosures. Emerald (`bg: rgba(16, 185, 129, 0.1)`, `text: #34D399`, `border: 1px solid rgba(16, 185, 129, 0.2)`) for "Ready for Cursor/Claude". Violet for "Prompt Generated".
- **Filter Chips**: Dark slate base (`#0F172A`), active state signaled by full indigo border and `#F8FAFC` text.

### Input Fields & Prompt Editors
- Dark inset backgrounds (`#0B0F17`), height 40px for single-line inputs, `space-sm` inner padding.
- Border is `1px solid rgba(148, 163, 184, 0.18)`. Focus state immediately applies `outline: none; border-color: #6366F1; box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.25);`.
- Placeholder text utilizes muted slate `#64748B`.

### Checkboxes & Selectors
- Checkbox dimensions: 18x18px, 4px border radius. Unchecked state: `#0F172A` fill with `border-subtle`. Checked state: `#6366F1` fill with an optical white check icon.

### Prompt & Code Preview Blocks
- Surface: `#070A10` (deepest black-slate) with a top utility bar containing a 1-click "Copy for Cursor" / "Export PRD" button. Code syntax highlighted using secondary blues, emerald, and violet.
