## DIRETRIZES FUNDAMENTAIS (REGRAS CRÍTICAS ANTI-ALUCINAÇÃO):
1. NÃO invente dependências externas além de: `@supabase/supabase-js`, `lucide-react`, `zod`, `tailwind-merge`, `clsx`, `zustand`.
2. Todos os componentes interativos devem declarar explicitamente `"use client";` no topo do arquivo.
3. Todas as mutações de banco devem ser processadas via Server Actions (`app/actions/*`) com validação rigorosa via Zod.
4. Nunca modifique schemas ou migrations sem fornecer comandos SQL compatíveis com Supabase Postgres.
5. Sempre respeite a convenção de layout da pasta `(dashboard)` sem reescrever o middleware global.

## STACK TECNOLÓGICA PADRÃO:
- Framework: Next.js 15.2.0 (App Router, Turbopack)
- Linguagem: TypeScript 5.5+ (Strict Mode: true, noImplicitAny: true)
- Estilização: Tailwind CSS v3.4+ com temas dinâmicos dark-slate
- Ícones: Lucide React (apenas SVGs otimizados)
- Banco de Dados & Auth: Supabase (PostgreSQL 15 + RLS ativado em 100% das tabelas)
- State Management: Server State com React Server Components; Local State via Zustand (apenas quando estritamente necessário).
